VERHALTEN

Einstellungen

Darstellung

Die Auswahl gilt für die gesamte Oberfläche einschließlich Dialogen und Diagrammen.

Vorauswahl für neue Slots

Diese Auswahl wird im Programmfenster nur vorgeschlagen. Sie wird niemals automatisch an das Ladegerät übertragen oder gestartet.

Standardmäßig ist kein Programm gewählt. Bereits vorbereitete Slots behalten ihre eigene Auswahl bis zum Ende des Programmlaufs.

Diagrammfarben

Livekarten und zeitbasierte Diagramme färben Laden, Pause und Entladen dezent ein. Zeiten außerhalb eines Programms bleiben neutral.

Einstellbar von 15 bis maximal 25 %. Start-/Stopp-Linien werden nicht mehr dargestellt.

Seitenschutz

Optionaler Login für Oberfläche, API und Live-Verbindung.

Das Passwort wird sicher gehasht gespeichert. Bei unverschlüsseltem HTTP schützt ein VPN oder HTTPS zusätzlich die Übertragung.

Datensicherung

Das Backup enthält Profile, Batterieakten, Messwerte und Einstellungen. Vor einer Wiederherstellung wird automatisch ein Rückfall-Backup angelegt.

Web-App

Die Oberfläche kann auf unterstützten Geräten wie eine eigenständige App installiert werden.
