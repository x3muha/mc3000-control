# MC3000 Control 1.0.0

The first stable release provides local control and long-term recording for multiple
SkyRC MC3000 chargers over Bluetooth Low Energy.

Highlights:

- responsive live dashboard, phase-aware charts and light/dark themes;
- profile library, capacity-based programs and portable JSON profile exchange;
- battery records, history, SOH/capacity reports, PDF/CSV exports and pack builder;
- German/English UI, read-only interactive demo and installable PWA;
- backups and anonymized diagnostics;
- optional authentication, login rate limiting and hardened browser/systemd settings;
- automatic tests on Python 3.11, 3.12 and 3.13.

## Raspberry Pi installation

Download `mc3000-control-1.0.0.tar.gz`, verify it with the adjacent `.sha256` file,
extract it, enter the directory and run:

```bash
./install.sh
```

The installer handles system packages, BlueZ, Python, the service account, systemd and
the post-start health check. Persistent data remains under `/var/lib/mc3000-control`.

Verified hardware combination: MC3000 hardware 2.2 with firmware 1.25. Direct USB and
Bluetooth SPP are not supported.

Always check battery chemistry, capacity, current, voltage and temperature limits before
starting a charger program.
